# 🏥 Hospital Management System (Java)

A console-based Java application for managing hospital operations such as doctor and patient records, appointments, and availability.

## 📌 Features

- Add, view patient records
- Add and manage doctor records- only by admin
- Book and cancel appointments
- Check doctor availability
- Search functionality across patients and doctors
- Basic database integration (MySQL / PostgreSQL supported)
- Date/time handling for appointment scheduling

## 🛠️ Tech Stack

- Java (JDK 8+)
- JDBC
- MySQL / SQL
- IntelliJ IDEA (used IDE)

## 🧱 Project Structure
- Doctors class
- Patient class
- Main (Book appointment) - main
